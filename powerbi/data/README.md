# Report data

These are compressed CSV exports for the four-page report. They contain the full snapshot: 31,509 applications, 1,202,267 events, seven audit results, their evidence and 56 evaluation cases. Nothing is sampled for the source-event page.

`manifest.json` records each table's row count and SHA-256. The original source fingerprint and reporting boundaries are also retained in `context.csv.gz`.

Source: Boudewijn van Dongen (2017), **BPI Challenge 2017**, Eindhoven University of Technology / 4TU.ResearchData. [Dataset and citation](https://doi.org/10.4121/uuid:5f3067df-f10b-45da-b98b-86ae4c7a310b).

The data remains under the publisher's [4TU General Terms of Use](https://doi.org/10.4121/resource:terms_of_use), separate from this repository's MIT code licence. Reuse and transformations are for non-commercial purposes. Further distribution must retain this source acknowledgement, including the original creator. These exports normalize timestamps and derive application-level metrics; they are not an official report from the source institution.
